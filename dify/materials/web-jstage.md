# J-STAGE
- id: web-jstage
- 形式: Web サイト（web）
- 著者・運営: 科学技術振興機構
- 系統: READ（読む）
- 伸びる小分類: 要旨把握（comprehension）、推論（inference）、批判的読解（critical_reading）
- 対象レベル: 7〜10（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: はい
- 言語: 日本語
- URL: https://www.jstage.jst.go.jp/
- タグ: 学術論文、要約、科学読解、一部有料
## 概要
国内学協会が発行する学術論文や研究報告を検索・閲覧できるプラットフォーム。要旨から結論まで、学術文章の構造を学べる。
## こんな人に
大学レベルの文章を読み、研究目的・方法・結果・限界を区別して要約したい人に効く。
