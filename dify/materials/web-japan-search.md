# ジャパンサーチ
- id: web-japan-search
- 形式: Web サイト（web）
- 著者・運営: 国立国会図書館
- 系統: READ（読む）
- 伸びる小分類: 要旨把握（comprehension）、推論（inference）、批判的読解（critical_reading）
- 対象レベル: 4〜9（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: はい
- 言語: 日本語
- URL: https://jpsearch.go.jp/
- タグ: 一次資料、探究学習、デジタルアーカイブ、公的機関
## 概要
国内の図書館、博物館、美術館、文書館などのデジタルアーカイブを横断検索できる公的プラットフォーム。資料の出典や年代を確認しながら読める。
## こんな人に
探究学習やレポートのために、一次資料を検索して背景と併せて読み解きたい人に効く。
