# 国立国会図書館デジタルコレクション
- id: web-ndl-digital-collection
- 形式: Web サイト（web）
- 著者・運営: 国立国会図書館
- 系統: READ（読む）
- 伸びる小分類: 要旨把握（comprehension）、推論（inference）、批判的読解（critical_reading）
- 対象レベル: 5〜10（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: はい
- 言語: 日本語
- URL: https://dl.ndl.go.jp/
- タグ: 一次資料、近代文献、デジタルアーカイブ、一部利用制限
## 概要
国立国会図書館が収集・保存するデジタル資料を検索・閲覧できる。近代の書籍、雑誌、公的資料などを原資料の形で読める。
## こんな人に
古い表記に挑戦したい人や、要約・比較読解のための信頼できる一次資料を探す人に適する。
