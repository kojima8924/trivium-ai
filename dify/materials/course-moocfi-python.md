# Python Programming MOOC
- id: course-moocfi-python
- 形式: オンライン講座（course）
- 著者・運営: University of Helsinki Department of Computer Science
- 系統: READ（読む）、WRITE（書く）、LOGIC（論理）
- 伸びる小分類: 要旨把握（comprehension）、根拠づけ（reasoning）、手順の追跡（tracing）、誤りの発見（debugging）、手順の設計（algorithms）、構造化・言語化（design）
- 対象レベル: 3〜7（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: はい
- 言語: 日本語
- URL: https://programming-26.mooc.fi/
- タグ: Python、英語、大学講座、自動採点
## 概要
ヘルシンキ大学の入門・発展プログラミング科目を公開したPython講座。豊富な自動採点演習を通じて基礎からオブジェクト指向まで進む。
## こんな人に
説明を読むだけでなく、大量の小課題で着実に実装力を定着させたい人に効く。
