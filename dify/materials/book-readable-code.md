# リーダブルコード
- id: book-readable-code
- 形式: 書籍（book）
- 著者・運営: Dustin Boswell・Trevor Foucher（オライリー・ジャパン）
- 系統: LOGIC（論理）、WRITE（書く）
- 伸びる小分類: 構造化・言語化（design）、明確さ（clarity）
- 対象レベル: 5〜8（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: いいえ（有料）
- 言語: 日本語
- タグ: コード品質、命名、定番、設計
## 概要
読みやすいコードの書き方（命名・コメント・制御の流れ）を短い例で示す定番書。
## こんな人に
動くが読みにくいと言われる人向け。文章の「明確さ」と同じ考え方が学べる
