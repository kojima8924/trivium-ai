# NHK NEWS WEB EASY
- id: web-nhk-news-web-easy
- 形式: Web サイト（web）
- 著者・運営: NHK
- 系統: READ（読む）
- 伸びる小分類: 要旨把握（comprehension）
- 対象レベル: 1〜3（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: はい
- 言語: 日本語
- URL: https://www3.nhk.or.jp/news/easy/
- タグ: ニュース、やさしい日本語、要旨、毎日
## 概要
ニュースをやさしい日本語で書き直したサイト。ふりがな・語の説明つきで、短い文章の要点を取る練習ができる。
## こんな人に
長い文章がまだ苦しい人向け。毎日 1 本、「何が起きたか」を一文で言い直す練習に使える
