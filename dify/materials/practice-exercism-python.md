# Python on Exercism
- id: practice-exercism-python
- 形式: 問題集・演習サイト（practice）
- 著者・運営: Exercism
- 系統: READ（読む）、WRITE（書く）、LOGIC（論理）
- 伸びる小分類: 要旨把握（comprehension）、根拠づけ（reasoning）、誤りの発見（debugging）、手順の設計（algorithms）、構造化・言語化（design）、推敲（revision）
- 対象レベル: 3〜8（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: はい
- 言語: 日本語
- URL: https://exercism.org/tracks/python
- タグ: Python、英語、自動テスト、コード改善
## 概要
テスト付きのPython演習を解き、解答例や自動分析から改善点を学べる。小さな課題を多数こなし、Pythonらしい設計へ進める。
## こんな人に
一度動いたコードを、読みやすく堅牢な解答へ改善する習慣を付けたい人に効く。
