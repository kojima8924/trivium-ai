# 国会会議録検索システム
- id: web-kokkai-kaigiroku
- 形式: Web サイト（web）
- 著者・運営: 国立国会図書館
- 系統: READ（読む）
- 伸びる小分類: 要旨把握（comprehension）、推論（inference）、批判的読解（critical_reading）
- 対象レベル: 6〜9（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: はい
- 言語: 日本語
- URL: https://kokkai.ndl.go.jp/
- タグ: 議論、一次資料、政治、批判的読解
## 概要
国会の本会議・委員会における発言を検索し、全文で閲覧できる。質疑、主張、根拠、反論の関係を追う教材として使える。
## こんな人に
長い議論から論点を整理し、発言者ごとの立場や前提を批判的に読み分けたい人に向く。
