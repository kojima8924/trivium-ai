# ライティング・ラボ「レポートの書き方資料」
- id: web-chuo-writing-lab
- 形式: Web サイト（web）
- 著者・運営: 中央大学アカデミック・サポートセンター
- 系統: WRITE（書く）
- 伸びる小分類: 構成（structure）、明確さ（clarity）、根拠づけ（reasoning）、推敲（revision）
- 対象レベル: 5〜7（1=誰でも、3=中学、5=高校標準、7=大学入試応用・社会人実務、9=専門家）
- 無料: はい
- 言語: 日本語
- URL: https://www.chuo-u.ac.jp/campuslife/learning_space/writinglab/
- タグ: 大学公式、レポート、入門、チェックリスト
## 概要
初めてレポートを書く学生が押さえるべきポイントを、大学のライティング支援部門が資料として公開している。
## こんな人に
長い専門書に入る前に、レポートの基本を短く確認したい高校生・大学生に向く。
